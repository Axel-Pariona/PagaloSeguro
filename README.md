# PagaloSeguro

Laboratorio de integración de pagos usando React, Supabase Edge Functions, PostgreSQL y Mercado Pago Sandbox.

## Stack

- React + Vite
- Supabase Auth
- Supabase PostgreSQL
- Supabase Edge Functions
- Mercado Pago Checkout Pro Sandbox
- Vercel

## Variables de entorno frontend

Crear `.env.local`:

```env
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
VITE_APP_NAME=PagaloSeguro
